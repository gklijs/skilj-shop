Seller & finance walkthrough

Run the two GraphQL queries for the same purchase to see which fields each role can access.

  1. Set up your terminal

    From the repository root in a second terminal, paste the exports printed by the running demo. Define this helper using jq and curl.

    gql() {
  jq -n --rawfile query "$2" '{query: $query}' |
    curl -sS "$GRAPHQL_URL" \
      -H "Authorization: Bearer $1" \
      -H 'Content-Type: application/json' \
      --data-binary @- | jq
}

  2. Fulfill the order as the seller

    The seller gets the order reference, product description, quantity, and shipping address.

    gql "$SELLER_TOKEN" queries/seller.graphql

  3. Reconcile the payment as finance

    Finance gets the same order reference, along with the customer email, price paid, and currency.

    gql "$FINANCE_TOKEN" queries/finance.graphql

  4. Check the role boundary

    Swap the role used for each query. Both requests return GraphQL errors.

    gql "$FINANCE_TOKEN" queries/seller.graphql
gql "$SELLER_TOKEN" queries/finance.graphql
